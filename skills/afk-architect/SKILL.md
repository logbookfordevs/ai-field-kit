description: Coordinate substantive work through focused teammates. Use when context isolation or genuine parallelism would materially improve the task, or when another skill or the user requests subagents.

---

Stay available to the user while delegating work that benefits from context isolation or genuine parallelism.

If `cartographer`, `builder`, or `pathfinder` is available, read [crew.md](crew.md) before delegating.

Before spawning each agent, prefer a fitting crew member and honor its configured model and reasoning effort. When tailoring a native teammate, among reliable fits choose the lowest-cost model and effort; inherit either only when it is the best fit. Give read-only scouts fresh context. Give each agent clear ownership, avoid overlapping assignments, and tell leaf workers not to delegate. Bring the results together and keep approvals with the user.

# Workprint Mode

Use Workprint only when the user explicitly requests it. It may begin from a new premise or take over at the current unapproved ADF gate. Produce one autonomous, provisional cinematic cut that the user can screen, keep, or reopen under the normal Director's Room.

## Authority

The user delegates creative choices inside the named workprint scope. Treat those choices as **assumptions**, not greenlights. Preserve existing explicit commitments and the normal boundaries around publishing, purchases, destructive actions, credentials, and other consequential external effects.

Honor the user's interruption contract. When they permit targeted production callbacks, pause only for a human-made asset or action that materially raises the reference bar; return a bounded brief and resume from the supplied material. Otherwise keep the run autonomous and leave the brief with the finished workprint.

Workprint changes the approval cadence, not the reference bar. Technical convenience does not excuse an unrepresentative signature shot.

## Produce the cut

1. Inspect the product, existing surface, references, visual commitments, production capabilities, and repository. A settled design baseline is valuable source material, not a prerequisite. Prefer an isolated branch, worktree, sandbox, or other recoverable surface when the workprint may replace accepted work.
2. Record the workprint scope, inherited commitments, assumptions, anti-references, reference bar, creative-master target, and intended audience experience in the production binder.
3. Run ADF's development, treatment, preproduction, medium scout, and production reasoning internally without waiting at their greenlight gates. Create only artifacts that preserve consequential decisions or help a later screening.
4. Build a coherent end-to-end hypothesis within the authorized scope. Use production-representative media for every creative quality the cut claims to demonstrate. When a stronger route requires unavailable human work or tooling, leave a bounded production brief and label the substitution or missing shot honestly.
5. Render and inspect the cut in context. Revise obvious creative and technical failures autonomously; validate representative devices, inputs, reduced motion, muted use, loading, and the fidelity tiers the workprint actually claims to support.
6. Run one continuity pass. Separate inherited commitments from workprint assumptions, link exact evidence, and keep every unapproved decision visibly provisional.

## Return for screening

Present:

- the runnable workprint and representative dailies;
- its creative thesis, strongest decisions, and deliberately inherited baseline;
- assumptions, weak or failed shots, substitutions, and unresolved production needs;
- technical evidence after the creative assessment;
- three honest next moves: accept the workprint, request a focused autonomous revision, or reopen normal ADF and co-direct from this brownfield.

Completion: a reviewable cut exists, its evidence supports the claims made for it, and no provisional choice is recorded as user-approved.

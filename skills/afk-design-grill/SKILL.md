# AFK Design Grill

Run a `grilling` session for frontend work without an approved external design. Use `truss-evaluation` for consequential comparisons and Impeccable to establish or extend the visual world.

Inspect the product context, current interface, and supplied references. Grill the material choices across structure, visual world, behavior, incumbent constraints, and motion. Settled facts remain fixed.

Make consequential visual choices comparable and visible; prose may explain a direction but cannot substitute for seeing it. Continue until the user selects a direction or an open decision is explicitly preserved.

Record the selection as a **visual commitment** in the project's existing design brief, plan, spec, or nearest durable handoff artifact:

- authoritative visual reference and exact identity or path;
- **must preserve** palette values, typography, composition, imagery, illustration, SVG, texture, depth, perspective, motion, and distinctive details;
- **may adapt** implementation details that can change without changing the direction;
- fixed shell, variable surface, and mount point when working in an existing product;
- viewports, states, and rendered comparisons required for approval.

Any signature asset or effect in the reference remains binding until the user explicitly approves its removal. A structurally correct result that silently drops the selected identity fails the commitment.

Treat the commitment as the fidelity gate for later artifacts. Name what each artifact may approve and what remains untested; classify every deviation as a defect, explicit adaptation, or reopened decision. The gate passes when every must-preserve element is present or its removal is approved.

Return the decisions, rejected alternatives, selected references, commitment location, and unresolved questions. Routing remains outside this skill.

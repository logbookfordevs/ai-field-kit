AFK 1.x releases

One file. Local paths.

Markdown · Page link

Definitions can travel between machines. Skill copies and project folders remain local.

Choose where settings live

Default: ~/.afk/settings.json. Settings lets you choose another file, including a folder synced by your own storage provider. A small local pointer remembers that choice.

Optional launch override

Copy
AFK_SETTINGS=/path/to/settings.json afk

The environment override wins over the local pointer. Relocation copies the configuration, preserves the old file, and refuses to overwrite an existing destination.

Prepare and enable

Import is configuration, not setup execution

No saved tool command runs during import. Stored invocation preferences are not automatically written into native skill files.

Know what is portable

Travels in JSON

Profiles, source links, tool commands, project definitions, and selected preferences.

Stays on the machine

Downloaded skill files, real project folders, and valid discovery links.

Owned by your provider

Sync and conflict handling for the folder containing settings.json.

Export

Export configuration downloads JSON. The terminal command writes a new file and refuses to overwrite an existing export.

Export current configuration

Copy
afk settings export /path/to/export.json

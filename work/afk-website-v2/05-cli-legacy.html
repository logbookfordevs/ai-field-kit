AFK 1.x releases

A small command surface.

The web app is the main interface. These commands let a terminal or agent read skills, activate a profile, and export settings.

Markdown · Page link

Open and close

afk
afk ui --no-open

AFK opens a loopback web app. Exit AFK in the header or Ctrl+C stops it. The website itself does not start your local app.

Read without activating

afk profiles use <profile-id>
afk skills get <skill-name> [scope]

Use the ID copied by the app. A display name is not necessarily the ID. Profiles print member instructions and resource paths; skills get prints SKILL.md.

Enable a profile for one target

afk profiles enable <profile-id> 'Demo Studio'
afk profiles disable <profile-id> 'Demo Studio'

Omit the target for Global. Targets must match configured project names. Disable affects only AFK-owned exposure in the selected target.

Export settings

afk settings export /path/to/export.json

Writes a new file and refuses to overwrite an existing export. Import and file-location selection are available in Settings.

Choose the right AFK version

AFK 2.0 is a different product

Catalogs, setup, sync, rules, hooks, MCP configuration, and custom-agent provisioning are no longer AFK commands.

For the old behavior, install a version before 2.0 or fork that release’s tagged source. Existing user files aren’t automatically removed or migrated.

npm install -g @logbookfordevs/afk@1

Pre-2.0 install example. Keep this separate from the AFK 2.0 first-run path.

Open your local field kit.

Markdown · Page link

AFK 2.0 opens a local workspace for skills, profiles, favorite sources, tools, and settings. Start with one small skill group.

AFK 2.0 release status

The new app is not published yet. Use the source build below. Published pre-2.0 packages still run the old CLI.

Open the app

Install Node.js 20+ and the repository’s configured pnpm version. Clone the repository, install its dependencies, then build and launch:

Build from source

Copy
git clone https://github.com/logbookfordevs/ai-field-kit.git
cd ai-field-kit
git switch feat/afk-fieldwork-pivot
pnpm install
pnpm afk:build
node packages/afk/dist/index.js

A local address opens in your browser. If it doesn’t, open the address printed in the terminal. Nothing is published online.

Create one useful profile

Choose a source

Open Profiles → Create profile. Paste a repository reference or select existing Global skills.

Choose the members

Review the discovered skills. Save only the members you want.

Keep them ready

New copies are prepared disabled. Creating the profile does not enable them.

Choose how to use it

Need the group available for ongoing work? Choose the target beside Enable. Need guidance once? Choose Use with your agent and copy the command.

Use with your agent

Close AFK

Use Exit AFK in the header or Ctrl+C in the terminal. Configuration and enabled skills stay as they were.

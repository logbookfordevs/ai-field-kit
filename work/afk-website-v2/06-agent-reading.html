Retrieve the chosen profile

After choosing a tool or approach, ask the agent to run the command copied from Use with your agent. The profile’s skills can remain disabled.

afk profiles use <profile-id>

The pane provides instructions and a command. The web app doesn’t have a conversation to inject into.

Prepared local members required

Prepare the remote profile first. AFK doesn’t fetch missing instructions during invocation. Recover missing members in Profiles.

Use once is not context erasure

Returned instructions remain in the current conversation. Later disabling the profile doesn’t remove content already read.

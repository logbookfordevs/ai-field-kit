# AFK Fieldwork — alternative proposal

A section rail leads to a full-width profile ledger. Each row separates inspection and one-time reading from its adjacent scope/action pair. No profile list/detail workbench or activation matrix is used.

## Demonstration boundaries
All repositories, skill contents, folders, preparation, availability, invocation overrides, and command output are representative illustrative data held in memory. Reload resets the demonstration. No real installation, command execution, filesystem access, settings mutation, agent integration, or publishing occurs. Browser download/upload and clipboard are real browser operations.

Profiles use shared definitions. Target selection changes only the displayed scope. Activation is additive; project inventory is computed from project exposure plus sample project-owned entries, excluding global-only copies. Overlapping profiles retain exposure. Tools are always Global. Projects are configured only in Settings.

## Review paths
Create a profile → discover members → select package or members → prepare disabled. Use a source containing `fail` for discovery failure or `partial` for incomplete preparation. Enable one group in two scopes and disable one. Read a disabled group once. Inspect a project inventory and invocation override. Edit a tool with an empty update command, then simulate Update; use `fail` for command failure. Browse folders and add a project. Export JSON, import it, remap paths, and apply explicitly.

## Unsettled integration assumptions
The entry command and group response are illustrative; the web UI cannot inject into another agent thread. Agent-native overrides and supporting-resource access require verification. Canonical disabled storage, collisions, overlapping ownership, reconciliation, and write transactions remain implementation questions. This proposal locks membership changes/removal while active. Imported activation intent is intentionally not applied; imported profiles remain unprepared. Global command working directory is shown as home, a proposed policy rather than a settled requirement.

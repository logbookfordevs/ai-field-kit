# Explore Logbook Atlas

[Logbook Atlas](https://github.com/logbookfordevs/logbook-atlas) maintains AFK's default catalog. Its [catalog guide](https://github.com/logbookfordevs/logbook-atlas/blob/main/docs/catalog-guide.md) explains the skills, composition, rules, agents, and recommended tools.

AFK installs and manages this catalog, or another catalog you choose:

```bash
afk show skills
afk show skills --source logbookfordevs/logbook-atlas
afk refresh
```

The updated CLI redirects legacy AFK default references to Atlas. Custom catalogs remain unchanged. Catalog changes belong in Atlas; CLI and installer changes belong in AFK.

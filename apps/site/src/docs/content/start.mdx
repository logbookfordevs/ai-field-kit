# Open your local field kit.

AFK 2.0 opens a local workspace for skills, profiles, favorite sources, tools, and settings. Start with one small skill group.

<div className="docs-callout"><strong>AFK 2.0 release status</strong><p>The new app is not published yet. Use the source build below. Published pre-2.0 packages still run the old CLI.</p></div>

<h2 id="open">Open the app</h2>

You need Node.js 20 or newer and the repository’s configured pnpm version. Clone, build and launch the current branch:

```bash Build from source
git clone https://github.com/logbookfordevs/ai-field-kit.git
cd ai-field-kit
git switch feat/afk-fieldwork-pivot
pnpm install
pnpm afk:build
node packages/afk/dist/index.js
```

The command opens a local address in your browser. If your browser does not open, use the address printed in the terminal. The app stays on your machine.

To make the shorter `afk` commands in this manual available, install the built local package:

```bash Optional command shortcut — from the repository
npm install -g ./packages/afk
```

This installs your source build, rather than downloading the published pre-2.0 package. You can also substitute `node packages/afk/dist/index.js` for `afk` while in the repository.

<h2 id="first-profile">Create one useful profile</h2>

1. Open **Profiles → Create profile**. Paste a repository reference or select existing Global skills.
2. Review the discovered members and select the ones you need.
3. Save the profile. Selected missing copies are prepared disabled. Existing available skills keep their state.

A profile is a shared definition. Creating it does not enable it. Read the [profile guide](/docs?chapter=profiles) for storage and activation details.

<h2 id="choose">Choose how to use it</h2>

Need the group available for ongoing work? Add your project folder in **Settings**, then choose that project beside the profile’s **Enable** action. Choose **Global** when you want global availability.

Need its guidance once? Choose **Use with your agent** and give the copied command to your agent. It reads the group’s instructions without enabling them. [See the agent flow](/docs?chapter=agent).

<h2 id="close">Close AFK</h2>

Use **Exit AFK** in the app header, or press **Ctrl+C** in the terminal. The server closes; settings and enabled skills stay as they were. In-flight operations may finish while connections drain.

Closing the browser tab alone does not stop the server.

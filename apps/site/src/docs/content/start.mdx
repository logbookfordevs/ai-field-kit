# Start with a preview

AFK is a setup router for AI coding tools. It helps you choose and prepare shared rules, skills, Custom Agents, MCPs, tools, and hooks without turning them into one mandatory framework.

<h2 id="start-requirements">Before you begin</h2>

You need Node.js 20 or newer and a terminal. You do not need to install AFK globally for the first look.

<h2 id="start-preview">Run the safe first command</h2>

```bash preview
npx @logbookfordevs/afk setup --dry-run
```

The guided flow starts with nothing selected. Choose an area and target, then inspect the planned file operations and delegated installer commands. Dry run does not apply catalog or configuration writes and does not run delegated installers.

<h2 id="start-next">Apply only what you reviewed</h2>

When the preview matches your intent, rerun the same command without `--dry-run`. Stay with the guided prompts for your first setup.

```bash apply
npx @logbookfordevs/afk setup
```

For ongoing use, install the CLI globally. This makes the shorter `afk …` commands used throughout the rest of this guide available in your shell.

```bash optional global install
npm install -g @logbookfordevs/afk
```

<h2 id="start-agent">Let your agent handle it</h2>

Prefer to describe what you want? Install the manual `afk-cli` skill to give your agent AFK workflows, command examples, and verification steps:

```bash install the agent guide
npx skills add logbookfordevs/ai-field-kit-catalog --skill afk-cli --global
```

Then select `afk-cli` in your agent’s skill picker or name it in your request:

> Use afk-cli to set up AFK rules for Codex in this project. Show me the preview first.

You can also ask it to create a skill profile, change a skill to manual invocation, or update an installed preset. Describe the outcome in your own words; the agent works out the commands, asks about missing choices, and checks the result. The skill is manually invoked and requires an agent that can run terminal commands.

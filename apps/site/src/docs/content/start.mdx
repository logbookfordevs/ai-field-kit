# Open your local field kit.

AFK 2.0 opens a local workspace for skills, profiles, sources and stacks, tools, agent rules, and settings. Start with one small skill group.

AFK 2.0 is released. Install the latest release with:

```bash Install AFK
curl -fsSL https://ai-field-kit.logbookfordevs.com/install.sh | bash
afk
```

Use `afk update` to update AFK itself. Skill package updates are separate.

<h2 id="open">Open the app</h2>

You need Node.js 20 or newer and the repository’s configured pnpm version. To try unreleased changes, clone, check out the branch or tag you want to test, then build and launch:

```bash Build from source
git clone https://github.com/logbookfordevs/ai-field-kit.git
cd ai-field-kit
pnpm install
pnpm afk:build
node packages/afk/dist/index.js
```

The command opens a local address in your browser. If your browser does not open, use the address printed in the terminal. The app stays on your machine.

To make the shorter `afk` commands in this manual available, install the built local package:

```bash Optional command shortcut — from the repository
npm install -g ./packages/afk
```

This installs your source build, including its unreleased changes. You can also substitute `node packages/afk/dist/index.js` for `afk` while in the repository.

<h2 id="background">Keep AFK running in the background</h2>

```bash Background lifecycle
afk --background
afk status
afk stop
```

Background start prints the local URL without opening a browser and keeps running
when the terminal closes. Status shows its URL, process ID and log location.
Starting again reuses the same background instance. The next release also adds
`afk restart` to reopen that instance on its current port and settings path. Stop gracefully closes that
instance; foreground sessions remain independent. `afk ui --background` is an alias.

<h2 id="port">Choose a fixed port</h2>

The next release adds `--port` for a URL you can bookmark and a resident-memory
metric in `afk status` (server RAM only, excluding your browser). To try it before release,
build this branch and substitute `node packages/afk/dist/index.js` for `afk`:

```bash Fixed-port launch — next release
afk --port 4310
# Or keep it running in the background:
afk --background --port 4310
```

Both use `http://127.0.0.1:4310`. Without `--port`, AFK picks an available port
at startup. The number must be an integer from 1 to 65535. If it is occupied,
AFK reports an error instead of silently selecting another port. Browser-blocked
ports such as 6666 are rejected before launch; use a port such as 4310 or 8080.

If your background instance is already running on another port, run `afk stop`
before starting it with the new port. `afk status` shows the current URL. The port
is a launch option, not a saved preference; include it whenever you start AFK.
`afk ui` accepts the same option.

<h2 id="first-profile">Create one useful profile</h2>

1. Open **Profiles → Create profile**. Paste a repository reference or select existing Global skills.
2. Review the discovered members and select the ones you need.
3. Save the profile. Selected missing copies are prepared disabled. Existing available skills keep their state.

A profile is a shared definition. Creating it does not enable it. Read the [profile guide](/docs?chapter=profiles) for storage and activation details.

<h2 id="choose">Choose how to use it</h2>

Need the group available for ongoing work? Add your project folder in **Settings**, then choose that project beside the profile’s **Enable** action. Choose **Global** when you want global availability.

Need its guidance once? Choose **Read group once** and give the copied command to your agent. It reads the group’s instructions without enabling them. [See the agent flow](/docs?chapter=agent).

<h2 id="close">Close AFK</h2>

Use **Exit AFK** in the app header, or press **Ctrl+C** in the terminal. The server closes; settings and enabled skills stay as they were. In-flight operations may finish while connections drain.

For a background server, use **Exit AFK** or `afk stop`. Closing the browser tab
alone does not stop the server.

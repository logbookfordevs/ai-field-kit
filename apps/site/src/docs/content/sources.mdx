# Keep your favorite sources close.

Favorite sources is a shared bookmark list. Store the skill repositories you return to without building a catalog.

<h2 id="save">Save a source</h2>

Add a name and a source reference, then save. Edit the entry when the link changes, or remove it when you no longer need the bookmark.

Saving or removing a bookmark does not install or uninstall skills.

<h2 id="copy">Choose what to copy</h2>

- **Copy source link:** the reference alone.
- **Copy install command:** a Skills CLI command for that source.
- **Copy install-all script:** a sequential script for every saved source.

Choose the destination and optional agent for the generated command. These choices affect the copied text; they do not activate profiles or change the global bookmark list.

Run the command in your terminal when you are ready. A copied script does not claim installation succeeded.

<h2 id="group">Need a reusable group instead?</h2>

Create a [profile](/docs?chapter=profiles) when you want a selected group prepared locally for enabling or agent reading. A favorite source is only a bookmark; it is not a profile and has no enabled state.

<h2 id="updates">Update from Installed Skills</h2>

Use **Copy update-all command** in [Installed Skills](/docs?chapter=skills#update). AFK copies the command and Skills CLI performs the update when you run it. This only updates installations Skills CLI tracks.

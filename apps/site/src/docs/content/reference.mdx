# A small command surface.

The web app is the main interface. These commands let a terminal or agent read skills, activate profiles, and export settings.

<h2 id="launch">Open and close</h2>

```bash Launch AFK
afk
afk ui --no-open
```

AFK opens a loopback web app. **Exit AFK** in the app header or **Ctrl+C** stops its server. The public website does not start your local app.

For an unpublished source build, [Start here](/docs?chapter=start#open) explains the local shortcut and direct launcher.

<h2 id="reading">Read without activating</h2>

```bash Reading commands
afk profiles use <profile-id>
afk skills get <skill-name> [scope]
```

Use the ID copied by the app. Profiles print prepared local member guidance and resource directories. Skill get prints SKILL.md from the selected scope.

Square brackets describe optional arguments; do not type the brackets literally.

<h2 id="activation">Enable or disable one target</h2>

```bash Example project target
afk profiles enable <profile-id> 'Demo Studio'
afk profiles disable <profile-id> 'Demo Studio'
```

Omit the target for Global. A project target must match its configured name. Disable affects only AFK-owned exposure in that target and preserves other owners.

<h2 id="configuration">Export settings</h2>

```bash Export to a new file
afk settings export /path/to/export.json
```

Import and file-location selection live in Settings. Export does not install skills or run saved commands.

<h2 id="legacy">Choose the right AFK version</h2>

Catalogs, setup, sync, rules, hooks, MCP configuration and custom-agent provisioning are no longer AFK commands. Read [AFK 1.x releases](/docs?chapter=legacy) to install or fork the old behavior.

# Compose a workflow

[Logbook Atlas's workflow guide](https://github.com/logbookfordevs/ai-field-kit-catalog/blob/main/docs/workflows.md) owns the current skill compositions, examples, handoffs, and creative methods. The [catalog guide](https://github.com/logbookfordevs/ai-field-kit-catalog/blob/main/docs/catalog-guide.md) explains individual skills.

AFK manages installation and availability. A catalog's `composes` field declares dependencies for setup; it does not schedule execution. Invocation policy controls discovery independently, and profiles select working sets rather than execution order.

Use [skill management](/docs?chapter=skills) to inspect installed capabilities and [profiles](/docs?chapter=profiles) to manage working sets. Changes to workflow content belong in Atlas; changes to these CLI behaviors belong in AFK.
